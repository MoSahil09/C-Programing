**Q1. Write a program to display the Sum and Product of two numbers by taking input from user.**

Sol :\
• Define input variable (say, num1 and num2)\
• Define operation variable (say, sum and product).\
• Take input using *scanf()* and store these values on defined variable.\
• take, *sum = num1 + num2* and *product = num1 * num2*.\
• print sum and product.


**Write a Program to Calculate the Area and Circumference of a Circle by taking Radius from User.**

Sol :\
• Declare input variable (say, radius, area and circumference).\
• Define π as constant.
• Take input using *scanf()* and store these values on defined/declared variables.\
• Do, *area = PI*radius*radius* and *circumference = 2*PI*radius*.\
• print Area and Circumference.
